AG-UI Workbench · an open-source protocol tool · AG-UI spec 1.0 · upstream protocol repo
Live mode sends your input only to the endpoint URL you enter. Built-in demos and file replay are fully local simulations: no language model, no agent framework, no network. Event validation checks each event against the official AG-UI 1.0 JSON Schema (bundled, MIT license, © 2025 the AG-UI authors, created by CopilotKit); it does not check event ordering or runtime behaviour, so it is not a full conformance suite. Validation runs on the bundled ajv library (MIT license). This project is not affiliated with or endorsed by the AG-UI project.
